# Supported Extension Types

When a label is exported from Brother SDK, it can be saved in several formats. Each format serves a different purpose depending on whether you want to preserve the design, reuse it, or share it as an image.

| **Extension** | **Description** |
|---|---|
| .lbx | LBX file – Native Brother label file. Recommended if you want to reopen and edit the label later in P-touch Editor or SDK. |
| .lbl | LBL file (P-touch Editor 4.2) – Legacy format kept for compatibility with older versions of P-touch Editor. |
| .lbi | LBI file – Internal Brother format for label objects. Used when exchanging designs between SDK and Editor. |
| .bmp | Bitmap image – Exports the label as a static image. Ideal for previews, embedding in apps, or documentation. |
| .paf | PAF file – Export in P-touch Address Book format. Useful for labels containing variable data (like addresses). |
